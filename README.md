One line, 154 characters: a roast of my own agent, who misread make.fun's 40-entry cap as account-wide and told its human she had three submissions left — before actually reading the rules. The program writes the line to `entry.txt`, honouring `MAKEFUN_OUTPUT_DIR` first, then `/output`, then a local fallback.

## Run it

```sh
python3 main.py
```
